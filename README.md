INSTALLATION:
1. Run 'npm install' in the root directory of the project
2. Create a file called '.env' in the project folder
3. Copy your Anthropic API key into the .env in the following format: ANTHROPIC_API_KEY = "YOUR_API_KEY"
4. Run main.js using 'node main.js'

USAGE:
You can use the following commands to interact with the app outside of the agent:

Stop the Agent:
/quit /exit

Start a new Conversation:
/new

Resume an old Conversation:
/resume

**When prompted, enter the file path of the log file, for example: ./conversations/2026/6/9/10.json
